# 🛠️ Bumble Cursor

> *Bumble Cursor*

---

**The problem:** A tiny bee takes over your cursor—no productivity, just wings.

**What it does:** A single-page toy that replaces the default cursor with a tiny bee and adds a gentle wing-vibration follow as you move, with one button to adjust the flutter.

**Born from:** ⚠️ GitHub Issue #6 by project owner
