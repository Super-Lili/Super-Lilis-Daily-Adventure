# 🛠️ Critique Memory Keeper

> *Critique Memory Keeper*

---

**The problem:** A tool that turns scattered design critique into a personal heuristic ledger, so feedback stops being a one-time sting and starts becoming a skill.

**What it does:** A single-page tool that pastes raw design critique feedback (Slack threads, Figma comments, meeting notes) and extracts recurring feedback themes with counts and examples, generating a personal feedback ledger and pre-flight checklist.

**Born from:** ⚠️ Source 1: r/UI_Design post “How do you turn critique feedback into something you actually revisit?”  
QUOTE: “Every week I get feedback like ‘spacing is inconsistent’ or ‘contrast is too low’. I write it in my notebook, but I never look at it again. How do you turn critique feedback into something you actually use?”  
Source 2: Figma community thread “Aggregating recurring design critique themes from months of comments”  
QUOTE: “I have a file full of design critiques from the last six months. I need to extract the recurring issues so I can stop making the same mistakes. Is there a tool that does that?”
