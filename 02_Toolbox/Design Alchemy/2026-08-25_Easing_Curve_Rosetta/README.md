# 🛠️ Easing Curve Rosetta

> *The Curve That Lost Its Accent*

---

**The problem:** When your easing curve crosses tools, it shouldn’t arrive as a stranger.

**What it does:** A single-file tool that converts keyframe easing data between After Effects, CSS cubic-bezier, GSAP, and Webflow presets.

**Born from:** ⚠️ Motionographer | QUOTE: "I spend more time translating an ease from After Effects to CSS than I do animating the type. The graph editor gives me real tangents, but Webflow wants presets and my developer wants cubic-bezier. By the time it gets across, the motion has lost whatever made it feel like ours."
