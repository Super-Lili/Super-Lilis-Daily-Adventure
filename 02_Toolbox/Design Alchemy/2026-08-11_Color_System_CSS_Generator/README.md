# 🛠️ Color System CSS Generator

> *The Hidden Cost of Perfect Color Tokens*

---

**The problem:** The quiet, unpaid step where a designer or developer manually types hex values into CSS custom properties—and the tiny tool that eliminates it.

**What it does:** A single-page tool that converts a plain-text list of color names and hex values into a complete CSS custom properties file, with light and dark mode variants clearly commented, ready to drop into any project.

**Born from:** ⚠️ `https://eyeondesign.aiga.org/the-token-tax-why-design-systems-still-require-manual-labor/
QUOTE: “Each time we update our brand color, our developers spend two days translating the hex values into CSS custom properties for dark and light themes—despite the tokens already being defined in Figma. It’s a tax we’ve come to accept.”`  
  *(link could not be verified - [🔍 search for this story](https://www.google.com/search?q=eyeondesign.aiga.org/the-token-tax-why-design-systems-still-require-manual-labor))*
